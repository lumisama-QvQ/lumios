# 文风

写 README、AGENTS、提交信息时照这个来，样本见 `README.md` 的 btrfs 小节。

- 一句话把因果说完，逗号串分句，不怕长：`这组件为了兼容遗留的服务器挂载逻辑，但桌面端启用会拖慢甚至数秒启动，这反而会导致有些软件工作非预期（比如clash-verge-rev），弊远大于利。`
- 中英混排不留空格，术语直接当句子成分：`silverblue自43起`、`2k等分辨率`。
- 先给事实和判断，再给做法，不铺垫：`但如今仍未修复`、`弊远大于利`。
- 列表写「动作 + 目的」：`注释掉 /etc/fstab 的 / 条目，解决systemd尝试重挂载的报错`。
- 具体到路径、命令、参数：`rootflags=subvol=root,compress=zstd:1`、`ostree#72`。
- 用「我们」自称：`这里我们通过…来修复它`。
- 不加过渡词，没有「首先/其次/总之/值得一提的是」；说完就停，不写总结段和升华句。
